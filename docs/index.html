Educational prototype

Lab results, viewed over time.

My Lab Trends is an early learning project exploring how a patient-facing application might help people view laboratory results as trends.

This is not a medical service. The project is not ready for patient use and must not be used to make health decisions. It does not currently connect to an electronic health record or process laboratory results.

About the project

The planned application is intended to be built with React, Vite, and JavaScript, with a future SMART on FHIR integration. At this stage, the repository contains project documentation only. No sign-in, FHIR launch, data import, storage, or sharing features are implemented.

Any future demonstrations should use synthetic data. Do not submit or enter real patient information, access tokens, passwords, or credentials.

Prototype limitations

This project has not been validated for clinical accuracy, safety, accessibility, or use with any healthcare organization. It does not provide diagnosis, treatment recommendations, urgent alerts, or medical advice. Talk with a qualified healthcare professional about your results and care.
