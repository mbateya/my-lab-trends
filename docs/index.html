Educational prototype

Lab results, viewed over time.

My Lab Trends is an early learning project exploring how a patient-facing application might help people view laboratory results as trends.

This is not a medical service. Use only the Epic non-production sandbox test account. This prototype is not for real patient care and must not be used to make health decisions.

About the project

The prototype is built with React, Vite, and JavaScript. It includes a browser-based SMART on FHIR connection to the Epic non-production sandbox for a standalone patient launch and read-only laboratory Observation retrieval. It has no backend or database.

Laboratory results are held in application memory while the page is open. SMART authorization state is held in the browser tab's session storage for the launch flow and is cleared when you disconnect or reload the app. Demonstrations should use only the Epic sandbox test account. Do not submit or enter real patient information, access tokens, passwords, or credentials.

Prototype limitations

This project has not been validated for clinical accuracy, safety, accessibility, or use with any healthcare organization. The connection is for non-production sandbox testing only. It does not provide diagnosis, treatment recommendations, urgent alerts, or medical advice. Talk with a qualified healthcare professional about your results and care.
