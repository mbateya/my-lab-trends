Privacy Policy

Effective date: November 1, 2026

Do not provide patient information or credentials. This prototype has no patient-data features and is not intended for real health information.

What this project currently does

My Lab Trends is an educational prototype. At this stage, its public website contains static project documentation. The project does not currently offer account creation, forms, analytics, advertising, a patient-data upload, or a SMART on FHIR connection. It does not intentionally collect patient information through the documentation pages.

Hosting and server information

If published with GitHub Pages, requests to this website are handled by GitHub's hosting infrastructure. GitHub may process technical information such as request and server logs under its own policies. This project does not control GitHub's hosting operations. Review GitHub's Privacy Statement for details.

Information you should not share

Do not send or post real patient information, protected health information, laboratory results, access tokens, passwords, or other credentials through this project, the repository, or its issue tracker. The prototype does not implement safeguards for receiving or storing such information.

Future changes

If the project later adds an application, integrations, or data handling, this policy should be reviewed and updated before those features are made available. This page describes the current documentation-only state, not a promise about future features.

Contact

For privacy questions about this project, use the contact or issue channels listed on its GitHub repository. Do not include sensitive or patient information in a message or issue.

This policy may be updated as the prototype changes. The effective date above identifies the current version.
