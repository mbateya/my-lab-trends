What this project currently does

My Lab Trends is an educational prototype. Its app connects in the user's browser to the Epic non-production FHIR R4 sandbox using SMART on FHIR authorization. When connected, it requests the current patient context and laboratory Observations so they can be shown on screen. It has no app backend, database, account system, analytics, advertising, or upload feature.

The app keeps laboratory Observation resources in page memory while the app is open and does not separately save those records to browser storage or a database. The fhirclient library uses the browser tab's session storage for OAuth state and the token response, including patient context needed for the active session. The app removes that local SMART session state when you disconnect or reload; it does not send a token-revocation request to Epic. Closing the tab also ends its session storage. Do not use real patient data or production healthcare systems with this prototype.
